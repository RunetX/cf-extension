# Дальнейшие поставки

1. Выполнено: рабочий скаффолд, stdio RPC, синтетика, CI и локальная упаковка.
2. Выполнено: native TreeView, палитра свойств, поиск, GUID references, состав,
   revision/dirty, подтверждение смены модели и атомарное сохранение. References —
   вхождения GUID, не семантический поиск BSL. XML экспорт — только новый/пустой каталог;
   открытый XML требует явного destination при сохранении.
3. Выполнено: BSL language server поверх общей модели: подсветка, живые синтаксические
   диагностики, обращения к известным коллекциям метаданных, автодополнение
   (коллекции менеджеров RU/EN, реквизиты и табличные части, экспортные методы общих
   модулей и менеджеров) и переход к определению (локальные имена, методы общих модулей
   и менеджеров, объекты метаданных — раскрытие в дереве). Без справочника платформы
   полный контекст глобальных имён недоступен: неизвестные имена не проверяются
   и не подсказываются, динамические типы не анализируются.
4. Следующая поставка: отладчик с отдельным DAP adapter.
5. Затем: визуальные редакторы и общая undo/redo инфраструктура; редактор форм последним.

Операции с живой базой и платформенными утилитами отложены. GitHub/Marketplace
публикация не входит в локальную сборку. Состав библиотечных форматов и ограничения
происхождения ресурсов описаны в README и provenance.md.
