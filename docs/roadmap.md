# Дальнейшие поставки

1. Рабочий скаффолд: open, stdio RPC, синтетика, CI и локальная упаковка.
2. Навигатор: дерево, свойства, поиск, GUID references, состав, revision/dirty,
   подтверждение смены модели и атомарное сохранение. References не являются
   семантическим поиском BSL. XML экспорт допускается только в новый/пустой каталог;
   для открытого XML сохранение требует явного destination.
3. BSL language server поверх общей модели.
4. Отладчик с отдельным DAP adapter.
5. Визуальные редакторы и общая инфраструктура undo/redo; редактор форм последним.

Операции с живой базой и платформенными утилитами отложены. GitHub/Marketplace
публикация не входит в локальную сборку.
