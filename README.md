# Конструктор 1С

Открывайте конфигурации 1С в VS Code: просматривайте дерево метаданных, находите объекты и меняйте их свойства.

## Возможности

- Дерево в привычном порядке Конфигуратора: объекты, реквизиты, табличные части, формы и другие группы, включая пустые.
- Поиск объектов по имени и синониму.
- Просмотр свойств и редактирование доступных полей: например, имени, синонима и комментария.
- Сохранение изменений в файл и выгрузка в XML.

Поддерживаются файлы **CF, CFE, EPF** и конфигурации в **XML**. Значки берутся из установленной 1С; если её нет, используются встроенные.

## Как начать

1. Установите расширение: в меню расширений VS Code выберите **Install from VSIX…** и укажите файл пакета.
2. Нажмите значок **«К»** на левой панели, затем **Открыть конфигурацию** в панели **Метаданные**.
3. Выберите файл. Для XML откройте каталог конфигурации, `Configuration.xml` или корневой файл внешней обработки.
4. Выберите объект в дереве — его свойства появятся ниже. После правки поля нажмите **Применить**, затем кнопку сохранения над деревом.

Поиск находится над деревом. Для сохранения копии или закрытия откройте палитру команд (**Ctrl+Shift+P**) и выберите **Конструктор: Сохранить как / XML** или **Конструктор: Закрыть конфигурацию**. При закрытии расширение предложит сохранить изменения.

## Что учитывать

Пока доступны просмотр метаданных и правка отдельных свойств. Редактор кода, отладка и визуальное редактирование форм ещё не реализованы. Недоступные для правки свойства показаны только для чтения.

Для выгрузки XML нужен новый или пустой каталог. Изменения открытого XML сохраняются в выбранное вами место. Для работы разрешите доверие к рабочей папке в VS Code.
