# Конструктор 1С

Открывайте конфигурации 1С в VS Code: просматривайте дерево метаданных, находите объекты, меняйте их свойства и редактируйте модули.

## Возможности

- Дерево в привычном порядке Конфигуратора: объекты, реквизиты, табличные части, формы и другие группы, включая пустые.
- Поиск объектов по имени и синониму.
- Просмотр свойств и редактирование доступных полей: например, имени, синонима и комментария.
- Открытие модулей в обычном редакторе: общие, объектов и менеджеров, форм, приложения и сеанса. Код подсвечивается, правки по Ctrl+S сохраняются в открытую модель.
- Проверка кода модуля прямо в редакторе: синтаксические ошибки и обращения к несуществующим объектам метаданных подчёркиваются сразу при вводе, без сохранения.
- Подсказки Ctrl+Пробел по открытой конфигурации: объекты коллекций (`Справочники.`, `Catalogs.` и др.), реквизиты и табличные части, экспортные методы общих модулей и модулей менеджеров, слова кода.
- Переход к определению F12: локальные процедуры и переменные, методы общих модулей и менеджеров — в нужный модуль и строку; имя объекта метаданных раскрывает его в дереве.
- Сохранение изменений в файл и выгрузка в XML.

Поддерживаются файлы **CF, CFE, EPF** и конфигурации в **XML**. Значки берутся из установленной 1С; если её нет, используются встроенные.

## Как начать

1. Установите расширение: в меню расширений VS Code выберите **Install from VSIX…** и укажите файл пакета.
2. Нажмите значок **«К»** на левой панели, затем **Открыть конфигурацию** в панели **Метаданные**.
3. Выберите файл. Для XML откройте каталог конфигурации, `Configuration.xml` или корневой файл внешней обработки.
4. Выберите объект в дереве — его свойства появятся ниже. После правки поля нажмите **Применить**, затем кнопку сохранения над деревом.
5. Модуль откройте из дерева (у объекта или общего модуля). Вкладка — обычный текстовый редактор: подсветка, undo/redo, Ctrl+S. Сам файл конфигурации перезаписывается только командой сохранения конфигурации.

Поиск находится над деревом. Для сохранения копии или закрытия откройте палитру команд (**Ctrl+Shift+P**) и выберите **Конструктор: Сохранить как / XML** или **Конструктор: Закрыть конфигурацию**. При закрытии расширение предложит сохранить изменения — как свойств, так и модулей.

## Что учитывать

Сохранение конфигурации сначала сохраняет все открытые изменённые модули, затем записывает файл. Смена или закрытие конфигурации с несохранёнными правками спрашивает подтверждение: «Сохранить», «Отбросить» или «Отмена». Проверка кода: синтаксис BSL, вызовы процедур и функций модуля и обращения к известным коллекциям метаданных (например, `Справочники.Имя`) сверяются с открытой конфигурацией. Подсказки и переходы опираются на метаданные открытой конфигурации: без справочника платформы неизвестные глобальные имена и динамические типы не проверяются и не подсказываются — выдуманных вариантов нет. Отладка и визуальное редактирование форм ещё не реализованы. Недоступные для правки свойства показаны только для чтения.

Для выгрузки XML нужен новый или пустой каталог. Изменения открытого XML сохраняются в выбранное вами место. Для работы разрешите доверие к рабочей папке в VS Code.
